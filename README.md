# DSA Practice

A collection of Jupyter notebooks for learning and practicing data structures and algorithms (DSA).

## Suggested learning order

1. **Introduction and problem solving** — `Intro.ipynb`, `Problemsolving1.ipynb`, `problem soving.ipynb`
2. **Sorting and searching** — `sortingalgorithm.ipynb`, `Binarysearchalogrithm.ipynb`
3. **Array techniques** — `prefixsum.ipynb`, `Two Pointers.ipynb`, `Sliding Window.ipynb`
4. **Hashing and collections** — `dictionary/hash.ipynb`, `set.ipynb`
5. **Core data structures** — `linkedlist.ipynb`, `Stack.ipynb`, `queue.ipynb`
6. **Recursion** — `Recursion.ipynb`
7. **Interview practice** — `amazonDSA.ipynb`

Python basics are in `python/python1.ipynb` and can be reviewed before starting if needed.

## Using the notebooks

Open the `.ipynb` files with Jupyter Notebook, JupyterLab, or VS Code. Work through the examples and practice problems in each notebook.
